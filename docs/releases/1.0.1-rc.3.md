Q-Podcasts 1.0.1-rc.3 combines the runtime-approved RC.1, RC.2 and RC.3 improvements. All three user runtime checks passed.

- Faster startup and navigation, lazy page/publisher loading, bounded background requests and smaller fonts. The main JavaScript bundle is about 75% smaller than the previously published build.
- Complete node-indexed catalog search and filters, persistent revision-aware metadata caching and clearer partial statistics.
- Durable publication drafts with saved files, stable episode IDs, safe continuation after closing the app, exact verification of uncertain uploads and protection against duplicate submissions.
- Actual QDN download/preparation status, audio buffering feedback, cancellation of stale player loads and reliable cover retry.
- New covers reduced to at most 1024 pixels on the long edge and 512 KiB, preserving smaller supported images.

Validation: 48 automated regression tests passed; TypeScript/production build and formatting checks passed; ESLint has no errors and five existing Fast Refresh warnings. Runtime files are checked against the exact RC.3 file hashes approved by the user before release packaging.

Downloads:

- `Q-Podcasts_1.0.1-rc.3_recovery-media.zip`: uploadable Q-App, with `index.html` directly at the ZIP root.
- `Q-Podcasts_1.0.1-rc.3_source.zip`: complete committed source, tests and documentation.
- `SHA256SUMS.txt`: release asset checksums.

Keep the APP name **Q-Podcasts**. Existing episode identifiers, links and playlists remain compatible. Recovery requires the same browser profile/origin and device; it cannot survive clearing/evicting site data. A closed tab's publication lease can take up to two minutes to expire. Payments retain their existing session-based uncertainty protection.

GitHub publication does not deploy the app to QDN automatically. The rc.3 version label is retained to match the tested build.
